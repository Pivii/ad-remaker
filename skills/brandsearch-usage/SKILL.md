# Brandsearch usage

Use Brandsearch only when its corresponding tools are available and authenticated.

1. Start from a brand domain, then retrieve the relevant summary, ads, social posts, emails, or products.
2. Search and filter creatives by the user’s vertical, date range, and performance criteria.
3. Prefer the available creative-download tool over temporary media URLs.
4. Before any credit-consuming analysis or transcription, check available AI credits and obtain approval for material spend.
5. Save findings to Brandsearch folders only when requested.
6. Include the record’s Brandsearch source link in the report when one is returned.
7. Treat index-size, coverage, and tool-behavior claims in the upstream document as historical documentation, not proof of current service state; verify them through the available tools when they matter.

See the verbatim [upstream source](references/upstream.md) for provenance and service-specific details.
