# Brandsearch

Brandsearch indexes 14M+ ecommerce stores and 400M+ ads, organic posts and emails.

- Start from a brand: look it up by domain, then pull its summary, Meta ads aggregates, TikTok/Instagram posts, emails and products.
- Find winning creatives across all brands with the Meta ad, TikTok and Instagram search and discover tools; filter by vertical, date and performance.
- To show a creative, use `download_ad` (it returns the image inline) instead of fetching a media URL: those URLs expire after 3 days and are often blocked.
- `analyze_ad` and `transcribe_ad` spend AI credits: check `get_ai_credits` before running them in bulk.
- Save findings with the folder tools (`list_folders`, `create_folder`, `add_to_folder`).
- Every record ends with a `Full data on Brandsearch` link: pass it on when you report a brand, ad or post.
