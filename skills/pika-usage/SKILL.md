# Pika usage

Use Pika only when its corresponding tools are available and authenticated.

1. Inspect the available tools and current schemas for the requested video, image, audio, or finishing operation.
2. Reuse an existing asset when the prompt and required output have not changed.
3. Before a billed render, state the model, duration or units, and estimated cost, then obtain explicit approval.
4. Submit only the approved generation and wait for its asynchronous completion.
5. Do not silently retry or expand the batch; present a new estimate and request approval.
6. Download outputs that must persist.
7. Treat capabilities, billing behavior, and tool availability in the upstream document as historical guidance until verified through current live tools.

See the verbatim [upstream source](references/upstream.md) for provenance and service-specific details.
