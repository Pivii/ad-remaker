# fal.ai usage

Use fal.ai only when its corresponding tools or API access are available and authenticated.

1. Search the available catalog for the required capability.
2. Inspect the selected model’s current input schema; never guess fields.
3. State the intended model, units, and estimated cost, then obtain approval before a paid run.
4. Upload local inputs only through an available authenticated upload mechanism.
5. Run inference with the required parameters and retrieve the resulting assets.
6. Download outputs that must remain available rather than relying on hosted URLs.
7. Treat model counts, pricing, authentication behavior, and platform capabilities in the upstream document as historical claims until verified against the current service or tools.

See the verbatim [upstream source](references/upstream.md) for provenance and service-specific details.
