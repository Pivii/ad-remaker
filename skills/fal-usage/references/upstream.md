# fal.ai

The fal MCP server gives your AI assistant access to 1,000+ generative models on the fal platform.

## Common workflow
1. Search for a model by capability (e.g. text-to-image, image-to-video, text-to-speech).
2. Inspect the model's input schema.
3. Run inference with the required parameters.
4. Upload local files when a model needs an input image, audio, or video.
5. Retrieve the generated output URLs.

## Notes
- The MCP server itself is free; you pay standard fal pricing for the model runs you trigger.
- Your API key is sent per request in the Authorization header and is never stored by the server.
- Get or manage keys at https://fal.ai/dashboard/keys.
