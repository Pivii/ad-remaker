# Pika

Use the Pika tools to generate and edit media: video (text-to-video, image-to-video, extend, lip-sync), image (text-to-image, edit, upscale, inpaint, background removal), audio (music, text-to-speech, voice cloning, transcription) and finishing (captions, trim, stitch, transitions).

Generation is asynchronous and billed to the connected Pika account: state the model and duration you intend to use before launching a render, and reuse an existing asset instead of regenerating it when the prompt has not changed.
